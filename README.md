# 🎬 Análisis sencillo de películas

Proyecto pequeño realizado con Python, Pandas y Streamlit.

## ¿Qué hace?

La aplicación utiliza un CSV pequeño de películas y permite:

- Ver los datos.
- Buscar una película.
- Filtrar por género.
- Ver algunas estadísticas.
- Ver una gráfica sencilla.

## Archivos

- `app.py` - código principal.
- `peliculas.csv` - conjunto de datos.
- `requirements.txt` - librerías necesarias.

## Ejecutar en la computadora

Instalar las librerías:

```bash
pip install -r requirements.txt
```

Después ejecutar:

```bash
streamlit run app.py
```

## Publicarlo

Puedes subir estos archivos a un repositorio de GitHub y después conectar el repositorio con Streamlit Community Cloud.

## Nota

El conjunto de datos incluido es pequeño y está preparado para fines educativos.
